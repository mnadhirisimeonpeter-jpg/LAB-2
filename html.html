📝 Hypertext Markup Language (HTML)

The standard language for creating and structuring web pages

HTML (Hypertext Markup Language) represents textual and image content on web pages. It is platform-independent — the text and content are encoded in a way that they can be displayed on a wide range of computers, regardless of operating system or device.

What is HTML?

HTML is the fundamental language of the World Wide Web. Every web page you visit is built with HTML. It uses a system of tags — special instructions enclosed in angle brackets — to define the structure and meaning of web content.

HTML is not a programming language (it cannot perform logic or calculations) — it is a markup language that describes how content should be structured and displayed in a web browser.

HTML was first created in 1991 by Tim Berners-Lee.

How HTML Tags Work

HTML tags usually come in pairs — an opening tag and a closing tag. Content goes between them:

<p>This is a paragraph.</p>
<h1>This is a Main Heading</h1>
<a href="http://www.strathmore.edu">Visit Strathmore</a>
<img src="images/logo.png" alt="Logo"/>
<strong>Bold text</strong>

Basic HTML Document Structure

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Page Title</title>
  </head>
  <body>
    <h1>Welcome to My Website</h1>
    <p>This is my first web page.</p>
  </body>
</html>

HTML with CSS and JavaScript

The Three Web Technologies

  • HTML — Structure and content ("the bones")
  • CSS (Cascading Style Sheets) — Visual presentation/styling ("the skin")
  • JavaScript — Interactivity and behaviour ("the muscles")

All three work together to create modern, dynamic web pages. HTML alone produces a plain, unstyled page.

💡 Key Fact: HTML was invented by Tim Berners-Lee in 1991. The current standard is HTML5, introduced in 2014, which added support for native audio, video, canvas drawing, and semantic elements without needing plugins like Flash.

📋 Domain Name Server (DNS)

The Internet's "phone book" — translating human-readable names into IP addresses

The Domain Name System (DNS) was created so people would not have to remember confusing numerical IP addresses. DNS translates human-friendly domain names (like www.strathmore.edu) into machine-friendly IP addresses (like 196.201.214.5).

Why DNS Exists

Every website on the Internet has a numerical IP address (e.g. 142.250.185.46 for Google). IP addresses are not user-friendly and would cause typing errors. DNS enables short, alphabetical names to be assigned to IP addresses, making them easier to remember and more informative.

Domain names are the unique names that identify a website — they are an alpha-numeric representation of the underlying IP address, with characters separated by dots (e.g. www.strathmore.edu).

Structure of a Domain Name

www.cnn.com

├── www → Machine name (host name)
├── cnn → Second-level domain (organisation name)
└── .com → Top-level domain (TLD)

Domain Name Levels

  • Top-Level Domain (TLD): The rightmost part of the domain name extension. Includes generic TLDs (.com, .org, .net, .edu, .gov) and country-code TLDs.
  • Second-Level Domain: The main, customisable part of the domain (e.g. "strathmore" in www.strathmore.edu). This is what organisations register.
  • Machine Name / Subdomain: The leftmost part, commonly "www". This identifies the specific server or service within the domain.

How DNS Resolution Works

  • You type www.strathmore.edu into your browser.
  • Your computer asks its DNS resolver: "What IP address does this name point to?"
  • The resolver queries DNS servers in a hierarchy until it finds the answer.
  • The DNS server returns the IP address (e.g. 196.201.214.5).
  • Your browser uses the IP address to connect to the web server.
💡 Key Fact: DNS is often called "the phonebook of the Internet." Without it, you would have to memorise the IP address of every website you visit. The global DNS system handles billions of lookups every day, in milliseconds.

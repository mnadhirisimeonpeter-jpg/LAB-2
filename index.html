Exploring Internet Terminology

This site covers the core terminology from Topic 1: Internet & the World Wide Web. Click any term below or use the navigation above to explore detailed explanations, diagrams, and definitions.

World Wide Web

A hypermedia information system spanning the globe

 📡

TCP/IP

The foundational communication protocols of the Internet

 🖥️

Web Browsers

Software to locate and display web content

 🗄️

Web Servers

Programs that serve content over HTTP

 🔗

URL

Uniform Resource Locator — the address of a web resource

 📋

Domain Name Server

Translates domain names into IP addresses

 🔄

HTTP

Hypertext Transfer Protocol — the web's request/response system

 🏢

Intranet

A private internal network for an organisation

 🤝

Extranet

A controlled extension of an intranet to selected partners

 ⚙️

Multitier Architecture

Layered design separating presentation, logic, and data

 📁

FTP

File Transfer Protocol — transferring files over a network

 📝

HTML

Hypertext Markup Language — the language of web pages

🔗 Uniform Resource Locator (URL)

The complete address that identifies the location of a resource on the web

A URL (Uniform Resource Locator) is an identifier for the location of a document or resource on the web. It is the complete specification of the location of an Internet resource, telling the browser exactly where to find it and how to access it.

Anatomy of a URL

http://www.library.strathmore.edu:80/resources/index.html

├── http:// → Protocol
├── www → Machine name (subdomain)
├── library → Second-level domain
├── strathmore → Domain name
├── .edu → Top-level domain (TLD)
├── :80 → Port number
└── /resources/index.html → Path to resource

Elements of a URL

  • Protocol — specifies how to access the resource (e.g. http://, https://, ftp://)
  • IP address or domain — identifies the server hosting the resource
  • Port number — port 80 for HTTP, port 443 for HTTPS (often omitted as it's the default)
  • Subdirectory path — the folder path from the document root
  • Resource name — the specific file (a default page is loaded if none is specified)

URLs, URIs, and URNs

TermFull FormPurpose
URIUniform Resource IdentifierThe general term — identifies a resource
URLUniform Resource LocatorIdentifies AND locates a web resource (most common)
URNUniform Resource NameProvides a globally unique name (not necessarily web-accessible)

📌 Important Note

A URL is a specific kind of URI. URI is the more general and technically correct term, though "URL" is the term most widely used in everyday language. All URLs are URIs, but not all URIs are URLs.

Examples of URLs

https://www.strathmore.edu
https://elearning.strathmore.edu/mod/assign/view.php?id=263535
ftp://files.example.com/documents/report.pdf
http://www.awbc.com/info/regesstepp/index.html
💡 Key Fact: The browser's default protocol is HTTP, so typing www.strathmore.edu is interpreted as http://www.strathmore.edu. Modern browsers upgrade this automatically to HTTPS when available.
